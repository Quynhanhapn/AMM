AMM GERMANY NUTRITION — TRANG NĂNG LỰC R&D

CÁCH UPLOAD
1. Giải nén file ZIP.
2. Upload toàn bộ file bên trong lên thư mục gốc GitHub của website AMM.
3. Không tạo folder mới. Tất cả file để cùng cấp với index.html, site.css và site.js.

GẮN LINK TỪ MENU TRANG CHỦ
Trong index.html, tại submenu “Năng lực R&D”, đổi đường dẫn thành:
href="nang-luc-rd.html"

Trang mới sử dụng lại site.css, site.js, logo, favicon và cờ ngôn ngữ hiện có của website.
